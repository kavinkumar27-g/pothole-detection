**Introduction**

Road potholes are a major cause of road accidents, traffic congestion, and vehicle damage. Traditional road inspection methods rely on manual surveys or public complaints, making pothole detection slow, costly, and inefficient.

This project proposes a Smart Pothole Detection and Road Monitoring System that uses a camera installed in people's vehicles to detect potholes in real time. When a pothole is detected, the system immediately alerts the driver, records the pothole's GPS location, and marks it on a digital map. Road authorities can access this map to identify damaged roads and prioritize repairs. By using everyday vehicles as mobile road monitoring units, the system enables continuous road monitoring, faster maintenance, and safer transportation.
